## 一、项目简介

`book-cli` 是一个基于 Python 实现的轻量级命令行图书管理工具，面向个人学习与课程实践场景。
它无需搭建 Web 服务和数据库，直接在终端完成图书的录入、查询、借阅、归还与列表查看，
数据以 JSON 文件本地持久化，便于初学者理解程序结构、文件读写与版本协作流程。

本项目同时作为《开源文化运动》课程的实践载体，完整演示开源项目从文档编写、许可证选择、
分支管理到社区互动（Issue、Star、Watch）的基本流程。

## 二、功能特性

- 图书录入：按书名、作者、分类、馆藏数量添加图书
- 图书查询：按书名 / 作者 / 分类检索
- 借阅与归还：记录借阅状态与剩余可借数量
- 列表查看：按分类或入库时间浏览全部馆藏
- 数据持久化：数据保存于本地 JSON 文件，退出后不丢失
- 命令行交互：提供清晰的菜单提示与错误提示

## 三、技术栈

- 语言：Python 3.10+
- 存储：本地 JSON 文件（无需数据库服务）
- 版本管理：Git + GitHub
- 无第三方运行时依赖，标准库即可运行

## 五、快速开始

1. 克隆仓库：

   ```bash
   git clone https://github.com/Asherandli/book-cli-27.git
   cd book-cli-27
   ```

2. 运行程序（无需安装第三方依赖）：

   ```bash
   python src/cli.py
   ```

3. 按终端菜单提示选择功能即可。

## 七、分支管理说明

项目采用 `main`（主干）+ `dev`（开发集成分支）+ `feature/*`（功能分支）的协作方式：

- `main`：稳定版本，保持可运行状态
- `dev`：日常集成分支，功能完成后合并回 `dev`
- `feature/xxx`：具体功能开发分支，从 `dev` 拉出，完成后合并回 `dev`
- 合并过程中如出现同一文件同一行的修改冲突，需手动编辑解决后再提交合并

详细操作步骤见仓库内《分支管理与协作指南》。
